## Build

Requires the Flutter SDK with Dart `^3.5.4` (the `environment` constraint in `pubspec.yaml`).

```
flutter pub get
flutter run
```

The repository ships placeholders instead of service identifiers (Firebase, Apple team, app group). Fill them in first: see [SETUP.md](SETUP.md).

## Name

The name "PublicOS" is used only by the official apps. If you publish a fork, give it its own name. The rules: https://publicos.dev/library/name-and-phrases/
